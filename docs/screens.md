# レポろく Ver 1.0 画面仕様

研修の録音・文字起こし・レポート出力アプリ。完全ローカル動作（外部通信は AdMob のみ）。

---

## タブ構成

下部に 3 タブ。中央の「録音」は他より大きく目立たせる。

| #   | タブ     | 役割                                           |
| --- | -------- | ---------------------------------------------- |
| 1   | ノート   | 過去のノート一覧・カレンダー・検索（表示切替） |
| 2   | **録音** | 新規録音の開始（中央・強調）                   |
| 3   | 設定     | 各種設定・ストレージ・バックアップ             |

**録音中は全タブを自由に行き来できる。** 画面下部に「録音中 00:42:15」のミニバーを常時表示し、タップで録音画面に戻る。

---

## 1. ノートタブ

ノート一覧・カレンダー・Todo・用語集は「同じデータの違う切り口」なので、タブを分けずに**表示切替**にする。上部にモード切替（セグメントコントロールかアイコンボタン）を置く。

```
[ リスト | カレンダー | Todo | 用語集 ]
```

### 検索

- どの表示モードでも常に上部に検索バー
- 文字起こし・メモ・タイトルを横断して全文検索
- SQLite FTS5 の **trigram トークナイザ**を使用（日本語対応のため必須）
- ヒットした箇所を前後の文脈つきで表示し、タップでその位置へジャンプ
- 検索中は表示モードに関わらずヒット結果のフラットなリストを表示する

### リスト表示（デフォルト）

- 新しい順に表示
- 「2026 年 8 月」のように月ごとの見出しでグループ化
- 各行に表示する情報
  - タイトル（未設定なら「2026/08/26 の研修」）
  - 日付・開始時刻
  - 録音時間
  - ★ の数 / 📝 の数 / ❓ の数 / 📷 の枚数
  - ファイル容量
- スワイプで削除（確認ダイアログあり）
- タップで**ノート詳細**へ

### カレンダー表示

- 月表示のグリッド
- 録音があった日にドットを表示（★ が多い日は色を変えてもよい）
- 日付タップでその日のノート一覧を画面下部に表示（リスト表示と同じ行デザイン）
- 左右スワイプで月を移動
- 「今日」ボタンで現在月に戻る

### Todo 表示

全ノートを横断して 📝 マークのブロックだけを一覧表示する。**単独の Todo アプリではなく、レポろくのノート機能の一部**として位置づける（他のノートと同じデータの見せ方の 1 つ）。

```
■ 未対応
□ [8/26 セキュリティ研修] 8/30までに2段階認証を設定
□ [8/24 先輩との面談] 議事録テンプレートを確認しておく

■ 完了
☑ [8/20 朝礼] 名刺を発注する
```

- チェックで完了 / 未対応を切り替え
- タップで元のノートの該当箇所へジャンプ（音声も含めて文脈を遡れることが強み）
- 期限日の入力・カレンダー連携は v1.1 に見送り（Ver 1.0 は 📝 を押した事実の記録のみ）

### 用語集表示

全ノートを横断して ❓ マークのブロックだけを一覧表示する。わからなかった言葉・社内用語をあとでまとめて調べたり、先輩に聞いたりするための一覧。

```
■ わからなかった言葉
・[8/26] 「シフトレフト」
```

- ❓ ボタンを押した際、「わからなかった単語」を短く入力するポップアップを出す（発言全体ではなく単語単位）
- ノート詳細の文字起こし内で、その単語部分だけを青字・下線のリンクにする
- リンクをタップすると用語集の該当項目にジャンプ
- 用語集側からもタップで元のノートの該当箇所に戻れる（双方向）
- 後から補足メモ（意味・説明）を追記できる

### 状態の記憶

- 直近選んでいた表示モードを覚えておき、次回起動時もそれで開く

## 2. 録音タブ → 録音画面

タブをタップすると全画面の録音画面へ遷移する。

### 表示

- 経過時間を大きく表示（`00:42:15`）
- リアルタイム文字起こし（自動スクロール、暫定結果はグレー）
- 確定したブロックには時刻を付与

### 操作ボタン（画面下部・大きく）

**画面を見ずに押せることが最優先。** 指の感覚で押し分けられる大きさと配置にする。

| ボタン      | 動作                                                       |
| ----------- | ---------------------------------------------------------- |
| ★ 重要      | 直近の発言ブロックに重要マークを付ける                     |
| 📝 ToDo     | 直近の発言ブロックに宿題・課題マークを付ける               |
| ❓ 質問     | 直近の発言ブロックに「わからなかった」マークを付ける       |
| 📷 スライド | カメラを起動し、撮影した写真をその時点のタイムラインに挿入 |
| ✏️ メモ     | 短いテキストを入力してその場に差し込む（録音は止めない）   |

- 押した瞬間にハプティクス（振動）で反応を返す
- 押されたブロックは色を変えて視覚的にも分かるようにする

### 制御

- 一時停止 / 再開
- 停止（確認ダイアログ → 保存してノート詳細へ）

### バックグラウンド動作

- 画面ロック中・他アプリ使用中も録音と認識を継続する
- iOS: `UIBackgroundModes: ["audio"]` を設定
- ロック画面に「レポろく：録音中 00:42:15」を表示する
  - 隠し録音にならないよう、録音中であることは常に可視化する
- 消費電力が大きいため、長時間録音時は充電を促す案内を出す

### 保存

- **認識が確定するたびに SQLite へ即書き込み**（メモリに溜めない）
- クラッシュしても直前までのデータが残るようにする

## 3. 設定タブ

### 再生

- 手前から再生する秒数（lead）: 初期値 1.2 秒、0.2 秒刻みで調整

### 録音

- 音声の品質 / サンプルレート（容量とのトレードオフを併記）
- 外部マイクを使う（初期値オフ）
  - 「オンにすると接続中のワイヤレスイヤホン等から録音します。離れた講師の声を録る場合はオフのままにしてください」

### ストレージ管理

- 総使用容量の表示
- ノートごとの容量一覧（大きい順）
- **音声データのみ削除**（テキストと写真は残す）
- 一括削除 / 選択削除

### バックアップ

- zip 書き出し（音声・写真・DB を含む）
- 共有シート経由でユーザーが保存先を選ぶ
- 自動クラウド同期は**採用しない**（「通信ゼロ」の方針に反するため）

### アプリ情報

- 言語（日本語 / English）
- 利用規約
- プライバシーポリシー
- オープンソースライセンス（MIT 等の表示義務に対応）
- お問い合わせ

## ノート詳細画面（タブ外）

一覧やカレンダーから遷移する。**アプリの中心となる画面。**

### タイムライン表示

文字起こし・メモ・写真が時系列で 1 本に並ぶ。

```
[00:03] 本日はセキュリティ研修を…
[00:47] ★ パスワードは使い回さないこと
[01:12] 📷 [スライド写真]
[01:30] 📝 8/30までに2段階認証を設定
```

### フィルタ

上部のチップで切り替える。

- すべて
- ★ 重要のみ
- 📝 ToDo のみ
- ❓ 質問のみ
- 📷 写真のみ

★ フィルタで「2 時間の研修を 3 分で振り返る」を実現する。

### 再生

- ブロックをタップするとその位置から再生
- lead 秒だけ手前からシークする（認識の遅延を補正）
- 下部に再生バー（再生 / 一時停止 / シークバー / 経過時間）
- 再生中のブロックをハイライト

### 編集

- テキストを長押し（またはタップ）で編集モード
- 誤認識の修正、追記が可能
- 編集したブロックには内部的に `is_edited` フラグを立てる
- ★ / 📝 は後からでも付け外しできる
- ノートのタイトルを変更できる

### 出力

- 右上に「レポート出力」ボタン → **レポート出力画面**へ

## レポート出力画面

### テンプレート選択

- **要点抜粋（デフォルト）** — ★ と 📝 と写真のみ
- 全文 — 文字起こし全体を含む

全文はオプション扱いにする。全文とスライド写真をそのまま社内配布すると、私的使用の範囲を超える可能性があるため。

### 出力例（要点抜粋）

```
【受講報告】新入社員セキュリティ研修
日時：2026/08/26 14:00〜16:00

■ 重要なポイント
・[00:47] パスワードは使い回さないこと
・[01:05] 不審なメールの添付ファイルは開かない

■ 今後のアクション
・[01:30] 8/30までに2段階認証の設定を完了させる

■ 自分のメモ
・[00:52] 次回は演習形式
```

### 書き出し方法

- クリップボードにコピー
- 共有シート（メール・Slack・LINE 等）
- テキストファイルとして保存

## 初回起動（オンボーディング）

1. アプリの概要説明（2〜3 画面）
2. **利用上の注意への同意**
   - 「録音・撮影は主催者の許可とルールに従ってください」
   - 「録音した内容の取り扱いは利用者の責任となります」
3. マイク権限のリクエスト
4. （Android のみ）日本語のオンデバイス認識モデルの確認
   - `getSupportedLocales()` で確認
   - 未インストールなら `androidTriggerOfflineModelDownload()` で誘導

## クラッシュ復旧

起動時に「未完了のセッション」が DB に残っていれば、ダイアログを表示する。

> 前回の録音が途中で終了しています。
> 2026/08/26 14:00 〜（42 分 15 秒）
> [復元する] [破棄する]

復元を選ぶと、そこまでのデータでノートを作成する。

## ホーム画面ウィジェット

「言われたことをすぐ録れる」ことが重要なため、ホーム画面ウィジェットから直接録音を開始できるようにしたい。ただし**優先度は最低**。

- タップで即座に録音開始（アプリを開かずに録れる）
- ウィジェット上に録音中かどうかの状態を表示
- iOS の WidgetKit（React Native から扱うには追加のネイティブ実装が必要）
- **まず iOS のみ**で検討する。Android は `react-native-android-widget` 等が必要でネイティブ実装の難度が上がるため、Ver 1.0 の他機能がすべて完成してから着手する
- コア体験（アプリを開いて録音ボタンを押す）との差は数秒程度であり、Ver 1.0 のリリースを遅らせてまで急ぐ機能ではない

---

## 広告（AdMob）

**録音中は絶対に広告を表示しない。** 全画面広告がオーディオセッションを奪い、録音が止まる危険があるため。

| 種別                 | 配置                                 |
| -------------------- | ------------------------------------ |
| バナー               | ノート一覧、カレンダー、設定の下部   |
| インタースティシャル | レポート出力の完了時                 |
| リワード             | （v1.1）PDF 出力などの追加機能の解放 |

## Ver 1.1 以降に回すもの

- 音声波形のリアルタイム表示
- 沈黙の長さによる自動セクション分け
- 再生速度の変更（1.25 / 1.5 / 2.0 倍）
- PDF 出力（写真入り）
- 音声の切り出し共有（★ の前後 30 秒など）
- m4a / AAC への変換によるファイル圧縮
- Todo の期限日入力とカレンダー連携
- 月次の振り返りサマリー
- 話者ボタン（会議用途に広げる場合）

## 不採用

- 証拠ログ / ハラスメント対策路線
  （ストア審査と法的リスク、研修特化という強みが薄まるため）
- 話者の自動識別
  （ネイティブ API に機能がなく、完全ローカルでは実現不可能）
- クラウド自動同期
  （「外部通信ゼロ」という最大の差別化要素と矛盾するため）
