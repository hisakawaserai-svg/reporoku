# レポろく (Reporoku)

研修・会議の**録音・文字起こし・ノートアプリ**。iOS / Android 対応。

話した内容をその場でテキストにし、重要・ToDo・質問のマークや写真・メモを同じタイムラインに残せます。あとから聞き返したり、要点だけ書き出したり、複数の記録を横断して未対応の宿題を追ったりできます。

「録音はしたけど、どこが大事だったか分からない」「宿題と質問がノートのあちこちに散らばる」「スライドの写真だけ後から迷子になる」——現場で起きがちなことを、1 本のタイムラインとまとめ画面で拾う想定です。

---

## 収録タブ — 話しながら残す

#### リアルタイム文字起こし
開始を押すと録音と同時に文字起こしが流れます。確定した発言には時刻が付き、タイムラインとして積み上がります。

#### ★・ToDo・質問を 1 タップで
画面を見ずに押せるマークボタンがあります。重要・宿題・わからなかった点を、その場の発言に付けられます。長押しすると直近の発言一覧から付け直せます。同じ発言に複数のマークを重ねることもできます。

#### 写真とメモ
カメラ撮影またはライブラリから写真を挟めます。短いメモも録音を止めずに入れられます。

#### 一時停止 / 終了 / リセット
一時停止はまだ記録の途中、終了でノートとして保存、リセットはここまでの内容を破棄して待機に戻します。

#### スリープモード
画面を暗くして直近の発言だけ出す省電力表示。ポケットに入れたまま録りたいときに使えます（誤解除しにくい長押し解除）。

#### 途中終了からの復旧
アプリが落ちても、次回起動時に「続きから録る / 内容だけ見る / 破棄する」を選べます。空の録音は自動で破棄されます。

---

## ノート詳細 — あとから聞き返す・直す

#### タップ再生
発言をタップすると、その位置から音声が再生されます。少し手前から聞き始められる lead 秒数は設定で変えられます。

#### 編集・結合・分割
長押しからテキスト編集、前後の発言との結合・分割、コピーができます。重要には一言メモやグループ、質問には回答、ToDo には完了など、種類ごとの操作もここから行えます。

#### フィルタとまとめタブ
上部フィルタで ★ や質問だけに絞り込めます。画面内の「まとめ」タブでは、そのノート 1 件分の重要・ToDo・質問・写真・メモを種類ごとに見られます。

#### 書き出し
要点抜粋（重要・ToDo・質問など）または全文を、コピー・共有・テキスト保存できます。写真付き PDF の書き出しにも対応しています。

---

## ノートタブ — 探す

#### リスト / カレンダー
月ごとの一覧と、記録のある日が分かるカレンダー表示を切り替えられます。

#### 検索
発言内容などからノートを探せます（短すぎる語では検索しません）。

#### 一括削除
リストで選択モードに入ると、ノートごとの使用容量も見ながらまとめて削除できます。

---

## まとめタブ — 複数の記録を横断する

複数の研修・会議をまたいで、未対応の ToDo・未解決の質問・重要な発言をまとめて確認できます。

- 完了済み・解決済みは初期状態では隠し、必要なときだけ開けます
- 質問は削除せず「保留」にできます
- 同じグループ名の重要は、ノートをまたいで 1 つのカードにまとまります
- 項目から元のノートの該当箇所へジャンプできます
- ToDo・質問は、録音なしでその場から追加もできます

---

## 設定タブ — 手間を減らす・データを守る

#### 再生・録音
再生開始位置（lead）、サンプルレート（標準 / 高音質）、外部マイクのオンオフ、セクション分けの初期間隔など。

#### ストレージ管理
ノートごとの容量確認、「音声のみ削除」（テキストは残す）、参照されていないファイルのクリーンアップ。

#### バックアップと復元
データベース・音声・写真を含むバックアップの作成と復元。機種変更時の移行用です。

#### 使い方
収録 / ノート詳細 / まとめ / ノート一覧 / 設定の説明をアプリ内に収録。各画面から該当セクションを開けます。

#### 初回オンボーディング
初回起動時に流れと利用上の注意（録音・撮影の許可と責任）を案内します。

## そのほか

- **日本語 / 英語** 対応（表示言語と、音声認識の言語は別々に選べます）
- 音声・文字起こし・ノート・写真は**端末内**に保存します。これらの記録データを外部サーバーへ送ることはありません
- 広告配信（AdMob）を利用する場合があり、そのための通信はあります（詳細は[プライバシーポリシー](https://hisakawaserai-svg.github.io/reporoku/privacy.html)）
- [利用規約](https://hisakawaserai-svg.github.io/reporoku/terms.html) / [サポート](https://hisakawaserai-svg.github.io/reporoku/support.html)

## 技術スタック

- **Expo**（React Native）+ TypeScript
- **React Navigation** — 下部 4 タブ + スタック
- **expo-sqlite** — 永続化（マイグレーション管理つき）
- **expo-speech-recognition** / **expo-audio** — 文字起こし・録音
- **expo-image-picker** — カメラ / ライブラリ
- **expo-print** / **expo-sharing** — PDF・共有
- **i18next** — 日本語・英語

## 開発

```bash
npm install
npx expo start
```

ネイティブビルドは `npx expo run:ios` / `npx expo run:android`（`ios/` `android/` は prebuild 生成物のため git 管理外）。

アイコンの再生成:

```bash
cd design/icons
python3 gen_reporoku_assets.py --install
```

## なぜソースを公開しているか

**透明性のためです。**

このアプリは、研修や会議の音声・文字起こしといった内容を扱います。手元の端末だけで完結し、記録そのものはどこにも送っていない ―― と説明することはできますが、閉じたアプリでは利用者にそれを確かめる手立てがありません。

だからソースを公開しています。何をしているアプリなのか、入力したデータをどう扱っているのかを、誰でも自分の目で検証できる状態にしておくためです。
